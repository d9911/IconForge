# IconForge

## Назначение

IconForge — браузерный инструмент для создания набора PWA-иконок и favicon из одного изображения пользователя.

## Веб-адрес

<https://icon-forge.d9911.org/>

## Подтверждённые возможности

- Выбирает изображение или принимает его перетаскиванием на страницу и генерирует PNG-иконки на canvas.
- Настраивает название и короткое название приложения, цвета темы и фона, радиус скругления, отступы, фон, а также полный или минимальный набор иконок.
- Генерирует полный набор в размерах 16, 32, 48, 72, 96, 128, 144, 152, 192, 256, 384 и 512 пикселей либо минимальный набор в размерах 16, 32, 180, 192 и 512 пикселей.
- **Примечание о минимальном наборе:** shortcut сгенерированного manifest ссылается на `icons/icon-96x96.png`, который минимальная настройка не создаёт. Для самодостаточного manifest/ZIP используйте полный набор либо добавьте иконку 96×96 вручную.
- Скачивает отдельные PNG, `favicon.ico`, сгенерированный `manifest.json` или ZIP-архив; manifest также можно скопировать в буфер обмена.
- Хранит настройки генератора в браузерном `localStorage`.
- Содержит web manifest и регистрирует `sw.js`, чей список кэша включает файлы приложения и URL JSZip. Это описание включённой реализации; поддержка браузером и доступность кэшированных ресурсов по-прежнему определяют её работу.

## Использование

1. Добавьте изображение выбором файла или перетаскиванием в область загрузки.
2. Настройте иконки и manifest, затем нажмите **Сгенерировать иконки**.
3. Скачайте нужные файлы по отдельности, ZIP-архив либо скопируйте/скачайте сгенерированный manifest.

## Локальная разработка и сборка

В репозитории нет package manifest, lockfile или локальной конфигурации сборки. Это статическое приложение: при проверке поведения service worker отдавайте репозиторий через локальный HTTP-сервер. Локальные команды установки или сборки не определены.

## Структура

- `index.html` — документ приложения, который регистрирует service worker.
- `src/script/` содержит загрузку изображений, генерацию иконок, генерацию manifest и общую браузерную логику.
- `src/style/` содержит стили страницы; `src/img/` — включённые иконки.
- `src/manifest.json` определяет manifest приложения, а `sw.js` содержит стратегию кэширования.

## Технологии и runtime-зависимости

Приложение использует браузерные HTML, CSS и JavaScript, API Canvas, File/Blob, Clipboard, `localStorage`, Web App Manifest и Service Worker. JSZip 3.10.1 загружается с cdnjs во время работы для создания ZIP. Конфигурация Node.js-зависимостей не отслеживается.
